# PARKING DETAILING KOZI

Αρχικός κώδικας για τη δίγλωσση ψηφιακή παρουσία της επιχείρησης PARKING DETAILING KOZI. Η εμπορική ονομασία διατηρείται όπως έχει οριστεί από την επιχείρηση.

## Περιεχόμενα αυτής της έκδοσης
- React, TypeScript και Vite.
- Ελληνική και αγγλική πλοήγηση.
- Αρχική σελίδα και κοινόχρηστο περιβάλλον.
- Αρχικές διαδρομές για στάθμευση, πλύσιμο και περιποίηση οχήματος, φόρτιση, προϊόντα, φωτογραφίες και επικοινωνία.
- Φωτογραφικό υλικό που έχει δοθεί για το έργο.
- Ρύθμιση δημοσίευσης μέσω GitHub Pages και GitHub Actions.
- Τεκμηρίωση αρχιτεκτονικής, μελλοντικής βάσης δεδομένων και προδιαγραφών περιεχομένου.

Οι επιμέρους σελίδες και οι λειτουργίες κρατήσεων, ηλεκτρονικού καταστήματος και διαχείρισης θα υλοποιηθούν στα επόμενα στάδια. Δεν παρουσιάζονται ως ήδη ολοκληρωμένες.

## 1. Δημιουργία GitHub Repository
1. Άνοιξε το https://github.com/new.
2. Στο πεδίο Repository name γράψε ακριβώς: `parking-detailing-kozi`.
3. Επίλεξε Public, εφόσον θέλεις η δοκιμαστική ιστοσελίδα να είναι δημόσια προσβάσιμη.
4. Μην επιλέξεις Add a README file, .gitignore ή license. Τα αντίστοιχα αρχεία περιλαμβάνονται ήδη στο πακέτο.
5. Πάτησε Create repository.

## 2. Ανέβασμα αρχείων
1. Αποσυμπίεσε το αρχείο ZIP.
2. Άνοιξε τον φάκελο `PARKING-DETAILING-KOZI`.
3. Επίλεξε όλα τα περιεχόμενα του φακέλου, μαζί με τους κρυφούς φακέλους όπως `.github`. Μην ανεβάσεις τον εξωτερικό φάκελο ως υποφάκελο.
4. Στο repository του GitHub επίλεξε Add file και Upload files.
5. Ανέβασε τα αρχεία και τους φακέλους στη ρίζα του repository.
6. Πάτησε Commit changes.

Σημαντικό: Βεβαιώσου ότι ο φάκελος `.github/workflows` έχει ανέβει. Περιέχει τη ρύθμιση αυτόματης δημοσίευσης.

## 3. Ενεργοποίηση GitHub Pages
1. Άνοιξε το repository και επίλεξε Settings.
2. Από το αριστερό μενού επίλεξε Pages.
3. Στο Build and deployment, όρισε ως Source το GitHub Actions.
4. Άνοιξε την καρτέλα Actions και περίμενε να ολοκληρωθεί επιτυχώς η εργασία δημοσίευσης.
5. Η διεύθυνση της ιστοσελίδας θα εμφανιστεί στις ρυθμίσεις Pages.

## 4. Τοπική εκτέλεση
Απαιτούνται Node.js 20 ή νεότερο και npm. Άνοιξε τερματικό μέσα στον φάκελο του έργου και εκτέλεσε:

```bash
npm install
npm run dev
```

Για έλεγχο παραγωγικής μεταγλώττισης:

```bash
npm run build
```

## Πριν από τη δημόσια παρουσίαση
- Να ενσωματωθεί το επίσημο λογότυπο της επιχείρησης αυτούσιο, χωρίς επανασχεδιασμό.
- Να αντιστοιχιστούν οι φωτογραφίες στις σωστές υπηρεσίες.
- Να επιβεβαιωθούν διεύθυνση, τηλέφωνο, ωράριο, τιμές και διαθέσιμες υπηρεσίες.
- Δεν έχουν ενεργοποιηθεί πραγματικές κρατήσεις, λογαριασμοί πελατών, παραγγελίες ή πληρωμές.
- Μην καταχωρίζεις πραγματικά προσωπικά δεδομένα ή στοιχεία πληρωμής στη δοκιμαστική έκδοση.

## Επόμενο στάδιο
Μετά τη δημιουργία του repository, στείλε τον σύνδεσμό του ώστε να συνεχιστεί η ανάπτυξη των επιμέρους σελίδων και των λειτουργιών demo, με αρχιτεκτονική που θα επιτρέπει μελλοντική σύνδεση με ασφαλές backend και βάση δεδομένων.
