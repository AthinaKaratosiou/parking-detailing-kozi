# PARKING DETAILING KOZI | Τεχνική αρχιτεκτονική

## Τρέχουσα δοκιμαστική έκδοση
- React και TypeScript για το περιβάλλον χρήστη.
- Vite για ανάπτυξη και δημιουργία της τελικής έκδοσης.
- GitHub Pages για τη φιλοξενία του στατικού frontend.
- GitHub Actions για αυτοματοποιημένη δημοσίευση.
- Τοπικά δεδομένα μόνο για μη ευαίσθητες δοκιμές.

## Μελλοντική παραγωγική λειτουργία
Η πραγματική λειτουργία κρατήσεων, λογαριασμών, παραγγελιών και πληρωμών απαιτεί backend. Η προτεινόμενη κατεύθυνση είναι PostgreSQL με Supabase ή αντίστοιχη υπηρεσία, ασφαλή ταυτοποίηση χρηστών, αποθήκευση πολυμέσων και διακομιστική επικύρωση.

Οι τιμές, η διαθεσιμότητα, η χωρητικότητα, τα δικαιώματα διαχειριστή και τα σύνολα παραγγελιών πρέπει να ελέγχονται στον διακομιστή. Δεν αρκεί ο έλεγχος από τον browser.

## Επιχειρησιακοί κανόνες που έχουν καταγραφεί
- Οι κρατήσεις στάθμευσης αφορούν διαθεσιμότητα χωρητικότητας και όχι συγκεκριμένη αριθμημένη θέση.
- Ο επιθυμητός ορίζοντας κράτησης είναι έως περίπου ένας μήνας, με τελικούς όρους προς επιβεβαίωση.
- Το δηλωμένο ωράριο είναι Δευτέρα έως Σάββατο 09:00 έως 22:00 και Κυριακή κλειστά.
- Η επιφάνεια εγκαταστάσεων έχει δηλωθεί στα 3.300 m².
- Οι τιμές και οι διαθέσιμες υπηρεσίες πρέπει να επιβεβαιωθούν πριν από τη δημοσίευση.

## Όρια της δοκιμαστικής έκδοσης
Δεν πραγματοποιούνται πραγματικές κρατήσεις ή πληρωμές. Δεν πρέπει να καταχωρίζονται πραγματικά στοιχεία πελατών. Η δοκιμαστική διεπαφή δεν αποτελεί ασφαλές σύστημα λογαριασμών.
